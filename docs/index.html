01 / What is Sentience?

Not another chatbot.
A working memory for your computer.

Sentience brings AI chat, local computer awareness, file history, model routing, memory, and privacy controls into one terminal-first workspace.

Ask about the project in front of you, inspect what changed, or attach documents deliberately. It works with the context you permit.
